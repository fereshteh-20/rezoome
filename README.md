# وب‌سایت رزومه و نمونه‌کارها

وب‌سایت شخصی و پورتفولیوی من با تم کهکشانی و کارت‌های شیشه‌ای (Glassmorphism).

---

## بخش‌های سایت
- **صفحه اصلی (`index.html`):** معرفی، مهارت‌های اصلی (طراحی سایت، مدیریت ریسک، ICDL) و خدمات فریلنسری.
- **صفحه ارتباط (`contact.html`):** راه‌های تماس مستقیم از طریق تلگرام، اینستاگرام، ایمیل و گیت‌هاب.
- **انیمیشن ستاره‌ها (`stars-canvas.js`):** پس‌زمینه ستاره‌ها و شهاب‌سنگ‌ها با HTML5 Canvas.

---

