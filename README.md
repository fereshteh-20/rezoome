# وب‌سایت شخصی و نمونه‌کارها — فرشته موری

وب‌سایت رزومه و پورتفولیوی چندصفحه‌ای با تم کهکشانی و افکت‌های شیشه‌ای مدرن (Glassmorphism).

---

## ساختار صفحات
- **`index.html` (صفحه اصلی):** صفحه ورودی متمرکز (تک‌پیج اختصاصی هیرو) شامل معرفی، سوابق فریلنسری و زبان‌های برنامه‌نویسی.
- **`skills.html` (مهارت‌های اصلی):** صفحه مستقل شامل ۳ کارت شیشه‌ای مهارت‌های کلیدی (طراحی سایت، مدیریت ریسک، مدرک ICDL).
- **`services.html` (خدمات):** صفحه مستقل معرفی خدمات قابل ارائه به کارفرمایان و پروژه‌های فریلنسری.
- **`contact.html` (ارتباط با من):** صفحه مستقل تماس مستقیم از طریق تلگرام، اینستاگرام، ایمیل و گیت‌هاب.
