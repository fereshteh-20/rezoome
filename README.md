# 🌌 وب‌سایت رزومه و نمونه‌کارهای فرشته موری (Cosmic Resume)

وب‌سایت شخصی و رزومه تعاملی **فرشته موری** با تم کهکشانی (آبی تیره و مشکی) و جلوه‌های بصری مدرن شیشه‌ای (Glassmorphism).

---

## 🌟 ویژگی‌های برجسته
- 🌌 **تم کیهانی و کهکشانی (Deep Space Blue & Black):** پس‌زمینه ستاره‌های شناور و شهاب‌سنگ‌های تعاملی با HTML5 Canvas.
- 💎 **کارت‌های شیشه‌ای (Glassmorphism):** نمایش ۳ رکن اصلی تخصص با افکت‌های نورانی نئونی و چرخش سه‌بعدی تعاملی (3D Tilt).
  1. **طراحی و توسعه وب‌سایت** (HTML5, CSS3, JavaScript, Python)
  2. **مدیریت و ارزیابی ریسک** (تحلیل، برنامه‌ریزی پاسخ به ریسک و کنترل بحران)
  3. **مدرک بین‌المللی ICDL** (تسلط بر مهارت‌های هفت‌گانه کامپیوتر و اکسل پیشرفته)
- 📱 **کاملاً واکنش‌گرا (Responsive):** طراحی چشم‌نواز در دسکتاپ، تبلت و تلفن‌های همراه.
- 🚀 **فوق‌العاده سریع و بهینه:** بدون هیچ کتابخانه سنگین جانبی (Zero-Dependency).
- ✉️ **راه‌های ارتباطی مستقیم:** اتصال به ایمیل و پیج کاری اینستاگرام (`@mwri_tech`).

## 🌐 نحوه مشاهده آنلاین با GitHub Pages
برای فعال‌سازی سایت به صورت آنلاین روی گیت‌هاب:
1. در صفحه مخزن **[fereshteh-20/rezoome](https://github.com/fereshteh-20/rezoome)** به بخش **Settings** بروید.
2. از منوی سمت چپ گزینه **Pages** را انتخاب کنید.
3. در بخش **Branch** شاخه `main` و پوشه `/ (root)` را انتخاب کرده و دکمه **Save** را بزنید.
4. آدرس رزومه آنلاین شما به صورت زیر خواهد بود:
   ```
   https://fereshteh-20.github.io/rezoome/
   ```
